
# موليه | Moule — الموقع الرسمي للضيافة الفاخرة والمناسبات بجدة

موقع إلكتروني متكامل وفاخر باللغة العربية أولاً لعلامة **Moule | موليه** في مدينة جدة، المتخصصة في ضيافات الأفراح الكبرى (Wedding Hospitality)، تنظيم حفلات الملكة والاستقبال، وتنسيق الهدايا والتغليف الفاخر.

---

## 💎 الهوية والتصميم (Design & Brand Identity)

- **لوحة الألوان المعتمدة (Design Tokens):**
  - العاجي الدافئ (`#FAF7F2` - Warm Ivory)
  - الإسبريسو العميق (`#30231F` - Deep Espresso)
  - الشامبانيا الناعمة (`#D7BD91` - Soft Champagne)
  - البيج المتناسق (`#E9DFD2` - Warm Beige)
  - الزيتوني المعتق (`#777B60` - Muted Olive)
- **الخطوط:** خط **IBM Plex Sans Arabic** للعناوين والنصوص العربية الفاخرة متناسقاً مع خط لاتيني كلاسيكي.
- **التخطيط:** دعم كامل لاتجاه النص العربي (RTL) مع تصميم متجاوب لجميع الشاشات (الهواتف الذكية 360px–430px، الأجهزة اللوحية 768px، وشاشات سطح المكتب 1280px+).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Next.js 14+** (App Router مع التوليد الثابت الفائق السرعة)
- **TypeScript** مع نماذج بيانات مصنفة بدقة
- **Tailwind CSS** مع رموز التصميم الخاصة بموليه
- **Lucide React Icons** لأيقونات عصرية وخفيفة
- **Structured Data (Schema.org)** للمطابقة مع محركات البحث واكتشاف الأعمال المحلية في جدة

## 🚀 التشغيل والتطوير المحلي (Local Development)

```bash
# تثبيت الحزم (إن لم تكن مثبتة مسبقاً)
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 📝 كيفية تخصيص وتعديل البيانات (Content Customization)

1. **معلومات الاتصال والفروع وروابط التواصل:**
   - قم بتعديل الملف: `src/config/site.ts`.
   - يحتوي على رقم الهاتف، الواتساب، رابط Google Maps، حساب إنستغرام وتيك توك، وبيانات الفرع الرئيسي وفرع الريان.
2. **المجموعات وأصناف الضيافة والصواني:**
   - قم بتعديل الملف: `src/data/catalogue.ts`.
   - يمكنك إضافة مجموعات جديدة، صور، وصف تفصيلي، وأسعار الصواني والتوزيعات.
3. **شريط الإعلانات الموسمي:**
   - يمكن تفعيله أو إخفاؤه أو تغيير نصه من خلال كائن `announcement` في `src/config/site.ts`.

## 📋 قائمة المراجعة والتحقق مع المالك (Owner Verification Checklist)

- [ ] **العنوان التفصيلي الدقيق لفرع حي الريان بجدة:** (تم وسمه حالياً في الموقع بأنه "قيد تأكيد العنوان النهائي" لمنع نشر عنوان غير مؤكد).
- [ ] **الصور الفوتوغرافية الرسمية لموليه:** تم تزويد الموقع حالياً بصور تحريرية نموذجية عالية الجودة؛ يُنصح برفع الصور الأصلية لصواني وتنسيقات موليه إلى مجلد `public` وتحديث مساراتها في `src/data/catalogue.ts`.
- [ ] **ساعات العمل المعتمدة:** التحقق من أوقات العمل في الأيام العادية وشهر رمضان ومواسم الأعياد وتحديثها في `src/config/site.ts`.
- [ ] **قوائم الأسعار الرسمية:** تم وسم الأسعار حالياً بـ "السعر عند الطلب بحسب عدد الصواني والتخصيص" لمزيد من المرونة والمصداقية.
